# 素数とは？

## 1. 素数の基本

\*\*素数（そすう）\*\*とは、1とその数自身以外で割り切れない、1より大きい整数のことです。

### 🍬 飴玉を分ける例

* x個の飴玉をn人で等しく分けられるか考えます。

* 例えば、5個の飴を2人で分けると、余りが出ます（5 ÷ 2 = 2 あまり1）。

* 5人で分けると、ぴったり1個ずつ配れます（5 ÷ 5 = 1 あまり0）。

* 1人と5人以外では等しく分けられない → 5は素数です。

* 2, 3, 5, 7, 11, 13, 17, … が素数の例です。

* 例えば、5は1×5しかできません。2×2.5や3×1.666…では割り切れないので、5は素数です。

* 6は1×6のほかに2×3でも割り切れるので、素数ではありません。

> **ポイント：** 素数は「かけ算のふたつのかけ算のかけ算」でできない数です。

---

## 2. なぜ素数が大切？

素数はシンプルですが、とっても大切な数です。

* 数学の研究で重要
* コンピューターでも特別な役割

特に、**IT分野の暗号化通信**（安全に情報を送る仕組み）で大活躍します。

## 3. 暗号化通信と素数の関係

### RSA（アールエスエー）暗号のしくみ

1. **大きな素数を2つ使う**

   * たとえば、素数 `p = 61` と `q = 53` を選びます。
2. **これらを掛け合わせる**

   * `n = p × q = 61 × 53 = 3233`
3. この `n`
を使って、メッセージを暗号化（ロック）したり、復号（アンロック）したりします。

   * 素数の性質のおかげで、かけ算は簡単だけど、元の素数に分解するのはとっても難しい！

この「かける・戻せない」仕組みを利用して、インターネットの**SSL/TLS**や**電子メールの暗号化**など、たくさんの安全な通信で使われています。

---

## 4. まとめ

* **素数**は1と自分自身でしか割り切れない数。2, 3, 5, 7, … が例。
* **暗号化通信**では、大きな素数を組み合わせて、データを安全に送る仕組みを作る。
* コンピューターのおかげで、ものすごく大きな素数を探して、安全な鍵を作っています。
